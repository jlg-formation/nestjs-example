# NestJS example

## Brief

Ce repository git contient un projet qui illustre le cours NestJS en 3 jours.
Le support de cours est donnes sous forme d'arborescence de fichiers YAML dans le repertoire `/specifications/`. Ce repertoire contient des chapitres, et un fichier YAML par slide.

On va construire petit a petit en suivant les slides le projet.
Un fichier TODO.md va montrer toutes les taches qui sont a faire tout en indiquant a quel slide YAML elle se refert.
Le repository contiendra des prompts github copilot `/.github/prompts/*.prompt.md`.

- un prompt `cree-todo` pour creer la todo liste
- un prompt `todo` pour generer un prompt detaille de ce qu'il faut faire

Les regles de codage, de refactoring, de style de code sont dans le fichier `/CODING_RULES.md`
