# NestJS example

## Brief

Ce repository git contient un projet qui illustre le cours NestJS en 3 jours.
Le support de cours est donné sous forme d'arborescence de fichiers YAML dans le répertoire `/specifications/`. Ce répertoire contient des chapitres et un fichier YAML par slide.

On va construire petit à petit le projet en suivant les slides.
Un fichier TODO.md va montrer toutes les tâches qui sont à faire tout en indiquant à quel slide YAML elles se réfèrent.
Le repository contiendra des prompts github copilot `/.github/prompts/*.prompt.md`.

- un prompt `cree-todo` pour créer la todo liste
- un prompt `todo` pour générer un prompt détaillé de ce qu'il faut faire

Les règles de codage, de refactoring et de style de code sont dans le fichier `/CODING_RULES.md`
